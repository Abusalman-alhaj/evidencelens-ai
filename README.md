# EvidenceLens AI

### AI-Assisted Startup Review & Technical Due Diligence

EvidenceLens AI is a full-stack application for reviewing startup
materials and performing AI-assisted technical due diligence.

Users can create projects, upload investment documents, analyze claims,
assess evidence, and review structured outputs generated by the backend
workflow.

The project explores how AI can support more transparent, traceable, and
structured analysis of startup materials.

## Features

-   User authentication and project ownership
-   Project creation and management
-   Document upload and PDF processing
-   AI-driven claim extraction and evidence analysis
-   Assessment scoring and provenance tracking
-   Dashboard and review workflows
-   API-based integrations for frontend interactions

## How It Works

1.  **Upload** --- Submit a startup pitch deck in PDF format.
2.  **Extract** --- Parse document content and identify candidate
    claims.
3.  **Analyze** --- Use AI-assisted processing to assess claims and
    identify relevant evidence.
4.  **Evaluate** --- Produce evidence-support assessments and highlight
    uncertainty.
5.  **Report** --- Generate structured outputs for human review.

## Environment Setup

### Backend

Navigate to the backend directory:

``` bash
cd backend
```

Create and activate a virtual environment.

**Windows PowerShell:**

``` powershell
python -m venv .venv
.venv\\Scripts\\Activate.ps1
```

**macOS / Linux:**

``` bash
python -m venv .venv
source .venv/bin/activate
```

Install dependencies:

``` bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Create your local environment file.

**Windows:**

``` powershell
copy .env.example .env
```

**macOS / Linux:**

``` bash
cp .env.example .env
```

Update the values in `backend/.env` as needed. Example local
configuration:

``` env
SECRET_KEY=your-very-long-random-secret

OPENAI_API_KEY=your-openai-api-key
OPENAI_MODEL=gpt-4o-mini

DATABASE_URL=sqlite+aiosqlite:///./evidencelens.db
DATABASE_URL_SYNC=sqlite:///./evidencelens.db

CORS_ORIGINS=http://localhost:5173,http://localhost:3000
UPLOAD_DIR=./uploads
MAX_UPLOAD_SIZE_MB=25
LOG_LEVEL=INFO
```

If you use PostgreSQL instead of SQLite, configure `DATABASE_URL` and
`DATABASE_URL_SYNC` with the appropriate PostgreSQL connection URLs and
drivers.

**Security:** Never commit `.env` files, database credentials,
authentication secrets, or API keys to GitHub. Keep the OpenAI API key
on the backend.

## Run the Backend Locally

From the `backend/` directory:

``` bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

-   API: http://localhost:8000
-   Swagger documentation: http://localhost:8000/docs

## Run the Frontend Locally

Open a separate terminal:

``` bash
cd frontend
npm install
```

Create `frontend/.env` and set the backend API URL:

``` env
VITE_API_URL=http://localhost:8000
```

Start the frontend:

``` bash
npm run dev
```

The frontend runs by default at http://localhost:5173.

## Run with Docker Compose

From the repository root:

``` bash
docker compose up --build
```

The Docker Compose configuration is intended to start:

  Service       Port
  ------------- ------
  PostgreSQL    5432
  Backend API   8000
  Frontend      3000

Use the configured Docker Compose environment variables and service
settings when connecting the frontend and backend.

## Run Tests

## Production Deployment

The repository includes configuration files for Render and Vercel.

-   **Backend:** FastAPI application deployed on Render
-   **Frontend:** React application deployed on Vercel
-   **Database:** PostgreSQL for production configuration

Configure production environment variables in the hosting provider's
dashboard. Important variables include:

-   `DATABASE_URL`
-   `DATABASE_URL_SYNC`
-   `SECRET_KEY`
-   `OPENAI_API_KEY`
-   `OPENAI_MODEL`
-   `CORS_ORIGINS`
-   `UPLOAD_DIR`
-   `MAX_UPLOAD_SIZE_MB`
-   `LOG_LEVEL`

Set `CORS_ORIGINS` to the deployed frontend origin. Confirm the
backend's CORS configuration supports the format provided.

Do not expose backend secrets through frontend environment variables.
Any `VITE_` variable included in the frontend build should be treated as
publicly accessible.

The live demo may be subject to API usage limits and hosting
availability.

## Current Limitations

EvidenceLens AI is an evolving project. AI-generated claim assessments
and evidence mappings may contain errors or require human review.

Evidence identified within a document does not necessarily establish
that a claim is independently verified. Assessment scores should be
interpreted in the context of the application's methodology.

The application is intended for exploratory and informational use, not
as a substitute for professional investment, legal, or technical due
diligence.
